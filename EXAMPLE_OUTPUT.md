## PowerShell Analysis Examples

### Load and analyze JSON data
```powershell
# Load the JSON file
$data = Get-Content rdr2_sites_20251115_180345.json | ConvertFrom-Json

# View search statistics
$data.search_stats

# Get all sites with instant delivery
$data.sites | Where-Object { $_.InstantDeliv -eq $true } | Select-Object Price, Region, URL

# Group sites by region
$data.sites | Group-Object Region | Select-Object Name, Count | Sort-Object Count -Descending

# Find cheapest prices (USD only)
$data.sites | Where-Object { $_.Price -like '$*' } | Sort-Object { [decimal]($_.Price -replace '[^\d.]','') } | Select-Object -First 10 Price, URL

# Count sites by source
$data.sites | Group-Object Source | Select-Object Name, Count

# Export instant delivery sites to CSV
$data.sites | Where-Object { $_.InstantDeliv -eq $true } | Export-Csv instant_delivery_sites.csv -NoTypeInformation
```

## What Each Symbol Means

- **⚡** = Site offers instant/digital delivery
- **🌍** = Region where the site was found
- **💰** = Price detected on the site
- **[number]** = Running count of sites discovered
- **N/A** = Price not found/detected on this site

## Performance Metrics Explained

- **Time**: How long the search has been running
- **Region**: Currently searching in this region
- **Found**: Total unique sites discovered so far
- **With Price**: Sites where a price was successfully extracted
- **Instant**: Sites offering instant/digital delivery
- **Rate**: Sites being discovered per second

## Tips for Best Results

1. **Let it run to completion** - The tool will automatically stop at 5,000 sites or when searches are exhausted
2. **Check both files** - JSON for data analysis, TXT for quick browsing
3. **Use CMD filters** - `findstr` is powerful for quick filtering
4. **Look for ⚡ symbols** - These are instant delivery sites
5. **Compare prices across regions** - Some regions have better deals
6. **Check the timestamp** - Files are named by date/time for easy organization
